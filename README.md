# Portfolio

A modern, animated portfolio built with React, Vite, Three.js, and Tailwind CSS.

## Features

- Smooth scroll animations
- Custom cursor
- Dark/Light theme toggle
- Responsive design
- Magnetic button effects
- Animated counters

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Tech Stack

- React 18
- Vite 5
- Tailwind CSS
- Three.js (WebGL black hole shader)
- React Three Fiber
- Lucide React (icons)
